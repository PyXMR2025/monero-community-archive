This could throw, leaving `pid_fd` still open. We most likely shutdown, so it's not terrible.

The easiest fix is to use `auto_scope_leave_caller` - that gets rid of all of these checks for close before quitting as closing is automatically handled everywhere.

## vtnerd | 2026-05-15T14:48:37+00:00
Also, are we concerned about TOCTOU issues? We may need to:

```c++
int pid_fd = open(pidfile.c_str(), O_NOFOLLOW, 0644);
if (pid_fd < 0)
  die(...);

if (fstat(pid_fd, &st) != 0)
  die(...);

if (!S_ISREG(st.st_mode))
  die(...);

std::string buf;
buff.resize(std::numeric_limits<int>::digits10 + 2);

ssize_t buf_len = read(pid_fd, &buf[0], buf.size());
if (buf_len < 0)
  die(...);

errno = 0;
int oldpid = 0;
buf.resize(size_t(buf_len));
if (buf.size() && boost::conversion::try_lexical_convert(buf, oldpid) && (kill(oldpid, 0) == 0 || errno == EPERM))
  die(...);

truncate(pid_fd, 0);
// ... remainder is same
```
