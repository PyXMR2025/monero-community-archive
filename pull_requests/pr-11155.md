# Original Description
Alternative to #11152. Redundant for consensus due to `cryptonote::core::check_tx_inputs_keyimages_domain()`, but will help us avoid playing whack-a-mole every time we use `crypto::check_ring_signature()` in wallet code or elsewhere.

Performance impact: one scalar-point multiplication, 4 field element reductions, and 5 32-byte string compares per call to `crypto::check_ring_signature()`. Daemons with checkpoints enabled will not take any performance impact.
