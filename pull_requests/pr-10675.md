# Original Description
- We do not include translations in releases and never have.
- We do not currently have someone interested in managing and maintaining a translation effort.
- None of the translations are finished:

```
fr: 81%
it: 63%
sv: 48%
de: 30%
ja: 23%
hi: 9%
es: 8%
nl: 4%
pl: 0%
sk: 0%
tr: 0%
pt-br: 0%
```

- None of the translations have been updated in 7 years.
- We do not have a glossary or translation guide, causing inconsistent or misleading translations.
- The current implementation has a dependency on `lrelease` (Qt), which I do not support.
- Translations for CLI tools have less expected utility than graphical applications.
- This repository has 44% more translatable strings than the GUI (1208 vs. 836), i.e. larger maintenance burden.
- As far as I can tell, there has been little to no demand for translations for `monero-wallet-cli` or `monerod`. No relevant issues were opened since 2018.
