# Original Description
Implements feedback in this comment by @j-berman: https://github.com/seraphis-migration/monero/issues/409#issuecomment-4595934444.  On Ed25519 compression failure for legacy enotes, sets the ECDH to the value `{1}`, which is the current `wallet2` behavior. This means that non-conforming legacy enotes, which are currently scannable, will remain scannable.

Also propagates failures in ECDH derivation in Carrot enotes.

Resolves #409
