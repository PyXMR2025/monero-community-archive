# Original Description
Reads payment IDs from tx extra nonce with `memcpy` instead of dereferencing `crypto::hash` / `crypto::hash8` pointers into string storage

The existing size and tag checks stay the same, so accepted bytes and failure cases do not change

The added unit coverage checks round trips plus wrong-tag, too-short, and too-long rejection

Tests:
- `cmake --build build/local-output-selection-tests --target unit_tests -j2`
- `build/local-output-selection-tests/tests/unit_tests/unit_tests --gtest_filter='cn_format_utils.*' --data-dir tests/data`
- `cmake --build build/local-output-selection-tests --target cncrypto-tests -j2`
- `cmake --build build/local-output-selection-tests --target cnv4-jit-tests -j2`
- `cd build/local-output-selection-tests/tests/crypto && ctest --output-on-failure`
- `cd build/local-output-selection-tests && ctest --output-on-failure -R '^unit_tests$'`
