# Original Description
Adds Nerva (XNV) as a monero_c target alongside monero/wownero/zano.

- `nerva_libwallet2_api_c` wrapper: `createTransaction` is adapted to Nerva's signature; the wallet2_api methods Nerva's wallet2 doesn't expose are stubbed as typed no-ops, so the exported symbol surface matches the other coins and the Dart/TS bindings need no special-casing.
- `nerva` submodule points at nerva-project/nerva (master), cross-built through Nerva's own `contrib/depends`, the same path as the other coins.
- `patches/nerva/`: `0001` CheckLinkerFlag source-dir, `0002` Version.cmake source-dir, and `0003` an apple-ios depends host (host Xcode + iPhoneOS SDK, boost c++14, zeromq ios->darwin). `0003` mirrors nerva-project/nerva#99; once that merges and the submodule pin moves to a commit including it, `0003` can be dropped.
- `impls/monero.dart`: `ffigen_nerva.yaml`, the `lib/nerva.dart` wrapper and its generated bindings, plus source checksums via `generate_checksum.sh` (`nerva_checksum.c` / `checksum_nerva.dart` / `checksum_nerva.ts`). `apply_patches.sh`, `build_single.sh`, `update_bindings.sh` and `generate_checksum.sh` all learn `nerva`.

Built green for linux x86_64, android (arm64-v8a, armeabi-v7a), iOS (aarch64) and macOS (arm64); `nerva.dart` is `dart analyze`-clean and the bindings/checksum sync checks pass.
