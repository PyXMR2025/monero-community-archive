I think it should be `HASH_DATA_AREA` here, because the layout of the 200-byte state is: first 136 bytes - `HASH_DATA_AREA`, last 64 bytes - `HASH_CAPACITY_AREA`. So this `memset` should clear the whole data area and leave capacity area intact so that enough entropy is preserved for the next permutation.
