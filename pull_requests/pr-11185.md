# Original Description
fixes #9332

`Wallet::store()` could serialize the cache while refresh was mutating wallet state, which could crash or leave a corrupted cache

use a shared guard for storage and the mutating part of refresh, returning false while either operation owns the guard

the final `refreshed()` callback stays outside the guard, so callers can still store once refresh has completed
