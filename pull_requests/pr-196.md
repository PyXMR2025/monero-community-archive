# Original Description
The C wrappers take int nettype, but wallet2_api's addressValid and keyValid each have two overloads: (…, NetworkType) and a deprecated (…, bool testnet). int converts implicitly to bool but not to the enum, so overload resolution always picks the deprecated one. Net effect: nettype 0 validates as mainnet, any nonzero value as testnet, and valid stagenet addresses/keys are always rejected.

Fix: static_cast the parameter to Monero::NetworkType at all six call sites (addressValid, keyValid, keyValid_error in both the monero and wownero wrappers) so the non-deprecated overload is selected and stagenet (2) is honored.

Fixes #190
