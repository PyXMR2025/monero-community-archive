# Original Description
With `--wallet-dir`, a startup `--password` (or `password=` in a config file) silently overrides the password given to `open_wallet`, `restore_deterministic_wallet` and `generate_from_keys`: the handlers `po::store` the request password into a copy of the startup options, and boost keeps the already finalised value. Restored/generated wallets end up encrypted with the startup password and `open_wallet` accepts any password for a wallet that shares it.
