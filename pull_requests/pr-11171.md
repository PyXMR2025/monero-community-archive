# Original Description
Implemented external IP to allow nodes behind NAT, containers, reverse proxies etc, to advertise a reachable external IP/port to peers. This tries to solve #5979, #10791.

Changes:

- added `--p2p-external-ip` supporting IPv4, IPv6 (`[addr]:port` and raw `addr`), with optional embedded ports
- generalizes Monero's existing `m_our_address` infrastructure (previously only populated for Tor `.onion` and I2P `.i2p` hidden services) for the public clearnet zone
- inject self-address into peerlist for public zone
- `--p2p-external-ip` accepts only IPs. `--p2p-external-port` accepts only ports, defaulting to bind/default port.
- added unit test cases covering valid IPv4, IPv6, and ports.

Passing release-tests.
