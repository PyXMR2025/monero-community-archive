# Original Description
Builds on top of:
  - #10362

Introduces the `get_tree_extension` function used to "extend" an existing (or empty) curve tree. This is the core tree building function. It accepts as params the number of leaves already in the tree, the current tree edge (the last hashes in every layer), and the new outputs to add to the tree. It uses those params to build a struct that can be used to extend the tree.

This PR also includes a unit test that constructs a tree in memory, extends it, and audits the result. It tests various tree structure combinations in an effort to capture as many edge cases as possible.

For more context on the tree and its place in FCMP++, see [these WIP docs](https://github.com/j-berman/monero/blob/7c6205403ed88924d48eb0dfb0a71140cd7902bb/docs/FCMP%2B%2B_INTEGRATION.md#2-curve-trees-merkle-tree) ([source PR](https://github.com/seraphis-migration/monero/pull/110)).
