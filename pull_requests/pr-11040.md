## thomasbuilds | 2026-08-10T04:46:44+00:00
`fail_msg_writer()` prepends `Error: ` on every call (`simplewallet.cpp:372-375`), so for HW
wallets the current form prints two `Error:` lines for a single failure.

Also `verify_password()` throws more than device errors - `error::file_read_error`
(`wallet2.cpp:5422`) renders the keys file path into `what()`, disclosing a filename the lock
screen otherwise hides by default (`show-wallet-name-when-locked`).

```suggestion
        if (m_wallet->key_on_device())
        {
          fail_msg_writer() << tr("Failed to unlock wallet: ") << e.what() << "\n"
                            << tr("Please ensure the hardware wallet is connected and unlocked.");
        }
        else
        {
          fail_msg_writer() << tr("Failed to unlock wallet.");
        }
```
