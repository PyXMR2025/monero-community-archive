# Original Description
issue: using basicswap (monero-wallet-rpc) connected to a healthy remote node over tor (responds to get_height w/o issue, so failover not triggered). Repeated sync fails which recover after the link improves. Monitoring the link shows that a 10MB response was being truncated at 6, 7, 8 etc MBs and trying again.

prior to 7760, the connection timer was reset before the write began. after,  it isnt reset until after the write completes - the write has to complete in whatever time remained, causing responses to be truncated and retried indefinitely (until the connection speeds up).

related fix: new connection timeout local was commented as 2minutes but the ms were 20mins. Change to 2min.
