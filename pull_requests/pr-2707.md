## thomasbuilds | 2026-09-17T11:29:53+00:00
Suggest 3 days instead of 14.

- In [Woodruff's analysis](https://blog.yossarian.net/2025/11/21/We-should-all-be-using-dependency-cooldowns) of 10 major supply-chain attacks, every npm one (chalk, Nx, rspack, web3.js) was pulled within 12h. The longer-lived ones weren't npm (tj-actions, Kong's Docker image, xz), so in that set going past 3d adds nothing pnpm can stop.
- 3d is what MetaMask, Uniswap and Astro use, and what Renovate's `config:best-practices` preset sets for npm (it covers npm's 72h unpublish window).
- pnpm 11 enforces this on every `--frozen-lockfile` install, so any lockfile update that pulls in a release younger than the window keeps CI red until it ages. At 14d CI is red until Sep 24, and security fixes wait two weeks unless excluded.

```suggestion
minimumReleaseAge: 4320 # minutes (3 days)
```
