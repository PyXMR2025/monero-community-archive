# Original Description
JSON-RPC notifications omit the `id` field and must be executed without returning a response

This keeps the existing request handling but suppresses response bodies for notifications, including error paths, while preserving explicit `null` ids as regular requests

Addresses the notification part of #11182

Tests:
- `build/tests/unit_tests/unit_tests --gtest_filter=http_server.json_rpc_notifications`
- `build/tests/unit_tests/unit_tests --data-dir build/tests/data`
