# Original Description
In the CLI wallet, input is typically requested from the user by means of text prompts (such as `Y/Yes/N/No`), however the behaviour of these prompts is often confusing and inconsistent. For example, the following message related to enabling background mining will be displayed upon creating a new wallet:

```
Do you want to do it now? (Y/Yes/N/No):
```

The "default" behaviour of this (what happens when you hit the 'enter' key without giving any input) is to set the option to "false". The user has no way to know this is the case (other than simply trying it and seeing what happens). Some other prompts (e.g. selecting a seed language, setting a restore date) will continue to ask the user until some input is given, or just abruptly exit the process.

I don't have any particular ideas of how this can be remedied at the moment, but it would be nice for an indication of the "default" option to somehow be provided for clarity and ease-of-use purposes.
