# Original Description
Closes #11003

## Changes

Currently, yes/no prompts in the CLI wallet do not indicate what the default behaviour is when pressing Enter. In practice, pressing Enter always defaults to No.

This PR:
1. Updates the function to display more detailed message instead of just Y/Yes/N/No
2. Refactors four call sites that manually appended the Y/N prompt string to use the existing  parameter instead, eliminating duplicated prompt formatting

## Testing

- Built and linked successfully with GCC 14
- All existing Y/N prompts now consistently show the default value
