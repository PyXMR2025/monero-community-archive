# Original Description
Label fields used for display and local history in `tools::wallet2::pending_tx` were not re-derived from trusted `construction_data` before storing them, unlike in `wallet2::sign_tx`. This would have allowed for poisoning of the submitter's transaction history and "repeatable nonce-burn griefing".

Unit tests were also added for this case, which were made using the help of an LLM, and verified by me.

Issue found by @thomasbuilds
