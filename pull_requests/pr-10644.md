# Original Description
If passing `keep_txs=false` in the RPC, or if using `pop_blocks` in the CLI with no additional flags, one can manually pop blocks much faster than before. This in done by skipping fetching/deserializing full transaction lists, and not adding them back into the mempool. This PR bumps the RPC minor version. One can retain previous behavior in the CLI by passing `keep-txs` to the `pop_blocks` command.

Resolves (or at least helps) #10207
