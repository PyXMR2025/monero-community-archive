# Original Description
Noticed wallet2::generate reads the multisig restore blob through `*(uint32_t*)` and `*(crypto::secret_key*)` casts straight off the byte buffer, which is an aliased read and undefined behavior. Switched them to memcpy into typed locals, the same change made recently for the levin buffer reads.
