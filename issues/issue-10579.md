# Original Description
A Floating Point Exception (FPE) crash was discovered in the crypto::ElectrumWords::checksum() function when fuzzing the mnemonic parsing code. This appears to be a divide-by-zero error that can be triggered with minimal input.

File: /src/mnemonics/electrum-words.cpp:209
Function: crypto::ElectrumWords::checksum()

Build Monero with fuzzing enabled and sanitizers (AddressSanitizer/UndefinedBehaviorSanitizer)
Run the mnemonic fuzzer: ./tests/fuzz/mnemonic_fuzz_tests ../tests/fuzz/mnemonic_corpus/
The crash is triggered with minimal input (single null byte: 0x00)

```
=================================================================
==12345==ERROR: libFuzzer: deadly signal
SUMMARY: libFuzzer: Floating Point Exception (FPE) in crypto::ElectrumWords::checksum at src/mnemonics/electrum-words.cpp:209
```
