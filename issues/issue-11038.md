# Original Description
When the CLI wallet is automatically locked due to inactivity, and the user is prompted for a password to unlock it, *any* password (including the correct one) will be rejected if the hardware device being used has also "timed out".

The correct behaviour in this situation would seemingly be to alert the user that the device must be unlocked as well.
