# Original Description
## Summary

Adds a short **Confirmation times** section to the Accepting Monero for Businesses page, explaining the standard 10-confirmation wait (~20 min at Monero's 2-minute block time) and linking to [OpenChainBench L1 Finality](https://openchainbench.com/benchmarks/l1-finality) for a live cross-chain reference.

The existing page links to a comparison matrix from 2019 but has no explanation of how long merchants should expect to wait for settlement. This section fills that gap with concrete numbers and a live benchmark for context.

- One new section appended at the end of the page
- No changes to existing content
- Open methodology, CC BY 4.0 data license
