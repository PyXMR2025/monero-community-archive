## SNeedlewoods | 2026-05-27T10:46:17+00:00
AFAICT underflow is unlikely, you would need something like e.g. `fork_time` 15 years in the future and `fork_block` at current height. 
But in case I'm missing something, do you think it would be sufficient to log an error and return 0?
Something like this:
```
-  else
+  else if (approx_blockchain_height > (fork_time - now) / seconds_per_block)
     approx_blockchain_height -= (fork_time - now) / seconds_per_block;
+  else
+  {
+    LOG_ERROR("Failed to approximate blockchain height from future fork block: " << approx_blockchain_height);
+    return 0;
+  }

```

## j-berman | 2026-05-27T20:33:58+00:00
I think that's a reasonable solution. The protection is good in case something gets introduced that messes with the logic and causes an underflow. The alternative is throwing, which is probably less desirable here.
