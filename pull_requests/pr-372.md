# Original Description
## Summary

Documents the current SOCKS proxy URL syntax for operators.

- monerod `--proxy` and `--tx-proxy`
- wallet-rpc `--proxy`

## Why

Issue #310 asks to add the new socks5 syntax. Public monero-docs still said SOCKS5 was "anticipated" and only showed bare `host:port`, while core `docs/proxies.md` and the daemon help string already document:

`[socks5://[user:pass@]]host:port`

## Source of truth

- https://github.com/monero-project/monero/blob/master/docs/proxies.md
- daemon `arg_proxy` help: `[socks5://[user:pass@]]<socks-ip:port>`

## Notes

- Bare `host:port` remains SOCKS4a (unchanged default).
- Mentions percent-encoding and preferring `--config-file` for credentials (same guidance as core docs).
- Links to core proxies.md for the full matrix.

Fixes #310

```suggestion
| `--proxy <arg>`              | Network communication through a SOCKS proxy (SOCKS4, 4a, and 5). Works with Tor, I2P outproxy, and commercial VPN/proxy services that speak SOCKS. Enabling this setting sends outbound IPv4/IPv6/hostname traffic through this proxy. It does not use Tor/I2P hidden services for P2P. It may be used with `--tx-proxy`: RPC-originated tx broadcasts follow `--tx-proxy`; other traffic uses `--proxy`. Format:<br>`[socks5://[user:pass@]]<socks-ip:port>` <br><br>Examples:<br>`./monerod --proxy=127.0.0.1:9050` (SOCKS4a)<br>`./monerod --proxy=socks5://127.0.0.1:9050`<br>`./monerod --proxy=socks5://user:pass@127.0.0.1:9050`<br><br>Bare `host:port` selects SOCKS4a. Prefix `socks5://` for SOCKS5; optional `user:pass@` with percent-encoding for special characters. Prefer `--config-file` for credentials. Full notes: core [proxies.md](https://github.com/monero-project/monero/blob/master/docs/proxies.md).
```
