# Original Description
- Compile monerod from the master branch
- Start syncing from the beginning
- At some point, it gets stuck on `Error adding block with hash: <...> to blockchain, what = Error adding spent key image to db transaction: MDB_MAP_FULL: Environment mapsize limit reached` error. There seems to be no fixed position where it gets stuck.
- After restarting the node, the sync continues, until it gets stuck again.
- It doesn't seem to be my storage. I tested using ramdisk for the data directory, same error after syncing for a while.
- It doesn't happen on the latest release binary.
- Tested on Arch Linux, Ubuntu, and FreeBSD. This behavior is consistent.
