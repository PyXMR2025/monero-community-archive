# Original Description
Hi,

After upgrading from 0.18.4.5 to 0.18.5.0 I am no longer able to send funds from my wallet.

Making a transfer with monero-wallet-cli was pretty fast before. Now it takes a long time and I eventually see this: `Error: RPC error: failed to get output distribution`

I tested with the exact same wallet on two synced nodes. One OpenBSD and one Debian.

Thank you!
