# Original Description
This is a partial address to issue https://github.com/monero-project/monero-gui/issues/4683. This PR implemented cli wallet's --extra-entropy function in GUI wallet.

The PR do the following jobs:
1.Implemented the UI for file selection
2.Implemented a helper function in OShelper that reads the file(capped at 64MB), and add it as extra entropy using the already implemented crypto::add_extra_entropy_thread_safe(...)
3.Regenerate the wallet using the newly mixed entropy after selecting the file
