# Original Description
This introduces 4 new crypto functions used in the FCMP++ integration:

- `mul8_is_identity_vartime`
  - Outputs that fail this check cannot enter the FCMP++ tree.
  - Such outputs are not spendable today.
- `clear_torsion_vartime`
  - Outputs must have torsion cleared **before** they enter the FCMP++ tree.
- `get_valid_torsion_cleared_point_vartime`
  - "`valid`" means that the point is able to be inserted to the FCMP++ tree.
  - If false, the point cannot enter the tree.
  - In addition to the point decompression check, we also make sure the point is not equal to identity **after** clearing torsion.
- `rct::verPointsForTorsion`
  - After the FCMP++ fork, we use this function to stop allowing outputs that fail `get_valid_torsion_cleared_point_vartime` OR have torsion from entering the chain.
  
  _______
  
An earlier state of this PR was audited by Cypher Stack and Trail of Bits:
- Cypher Stack (and @Boog900) identified a redundant check for mul8 is identity in the torsion clear.
  - Cypher Stack section [6.4.2](https://github.com/cypherstack/fcmp-impl-audit/blob/d7de33d08c48a3c249629e47f71ea72c938a3404/FCMP_Code_Implementation_Audit.pdf).
- Cypher Stack recommended suffixing vartime functions with `_vartime`.
  - Section [6.5](https://github.com/cypherstack/fcmp-impl-audit/blob/d7de33d08c48a3c249629e47f71ea72c938a3404/FCMP_Code_Implementation_Audit.pdf).
- Cypher Stack recommended using the scalar type for `EC_INV_EIGHT`.
  - Section [6.3.2](https://github.com/cypherstack/fcmp-impl-audit/blob/d7de33d08c48a3c249629e47f71ea72c938a3404/FCMP_Code_Implementation_Audit.pdf)

All are remediated in the latest version of this PR.

Trail of Bits did not identify issues with this PR in their audit. Will share their audit once it's public.
