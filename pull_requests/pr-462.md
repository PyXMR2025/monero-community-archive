# Original Description
Resolves #389
Related: https://github.com/monero-project/monero/pull/10941

1) if coinbase `unlock_time >= FCMP++ fork height`, then require at least 1 coinbase out, and start doing FCMP++ torsion validation.
2) Require FCMP++ txs' `(reference_block+1) >= FCMP++ fork height`.

We want unique tree roots so that a tx with `reference_block=m` can't possibly have a valid membership proof for some other `reference_block=n`.
