## jeffro256 | 2026-09-08T20:13:06+00:00
I'm pretty sure that this is the wrong minimum version. It should be 1.81 AFAICT. See the `fcmp++` branch in `monero-oxide` 

## j-berman | 2026-09-14T20:33:01+00:00
Minimum version according to the `fcmp++` branch would be 1.81, though @kayabaNerve raised a valid argument over DM in favor of setting our minimum here to 1.85. Some of the arguments:
- 1.85 introduces the 2024 edition of Rust bringing a ton of new major features in Rust that we can eventually take advantage of.
- It's the version Debian ships.
- It's the version a lot of the ecosystem using Rust sets to its minimum target these days.

## kayabaNerve | 2026-09-14T23:04:12+00:00
And even if we officially require a minimum of 1.85, we should always recommend the latest patch release of newer minor versions for performance reasons. Codegen improves over time.
