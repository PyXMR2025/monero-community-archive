# Original Description
removeTemporaryWallet() was only called on the successful save path, leaving wallet key files behind in the temp directory whenever a wallet creation or restore was abandoned, failed, or retried.

Consolidate cleanup into closeTemporaryWallet(), which closes the wallet before removing the files (the wallet stores its cache on close, which would recreate the file) and skips deletion while createWalletFromDeviceAsync() is writing the files on another thread. It runs on wizard restart, before creating a replacement wallet, and when quitting mid-wizard; failed restore and device creation remove their files directly after closing the wallet.

Block wizard input during asynchronous device wallet creation: the processing splash does not block the wizard, so navigating back to the wizard home could delete the files while they were being created. deviceWalletCreationInProgress tracks the creation because the device passphrase dialog re-enabled the wizard when closed, and restart() keeps the walletManager connections while it is set so a late walletCreated still cleans up.
