# Original Description
If passing `keep_txs=false` in the RPC, or `no-keep-txs` in the CLI, one can manually pop blocks much faster than before. This in done by skipping fetching/deserializing full transaction lists, and not adding them back into the mempool. This PR bumps the RPC minor version.

Resolves (or at least helps) #10207
