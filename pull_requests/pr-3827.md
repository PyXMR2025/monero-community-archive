# Original Description
This adds in support for PowerPC devices (including 32-bit PPC, 64-bit PPC little endian, and 64-bit PPC big endian [such as Power8 and Power9). Whilst I don't have a device to test PPC64, a VM did show a successful run, despite being incredibly slow. On hardware, I tested on a Nintendo WiiU running Gentoo Linux and got what you'd expect performance-wise. I completely understand if this is outside the scope of this project to support such an esoteric architecture, just wanted to throw this here in case it was useful.
