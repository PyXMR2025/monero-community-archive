# Original Description
https://github.com/monero-project/monero/pull/5821 was rejected because it added runtime code to critical code path, so I'm suggesting this alternative. For security reasons it's only run on pull requests, the full tests are still run on merge.

Splitting up `core_tests` from the other tests also has the advantage that the more frequently failing tests run first.

Reduces `core_tests` runtime from 2610.67 sec to 273.01 sec (~90% reduction).
