# Original Description
Rationale: 
 
- Daemon bootstrap was added in #3165 when Monero was younger, to make slow initial sync less painful and encourage users to run local nodes.
- In practice, it's hidden behind a flag that most beginners would never set, so the target audience likely does not use it, except indirectly through `monero-gui`.
- Users can already manually switch to a remote node when needed.
- Automatic bootstrap discovery is being abused by spy nodes.
- `monero-gui` is being [updated](https://github.com/selsta/monero-gui/tree/simple-mode) to avoid using bootstrap functionality.
- Bootstrap support adds a lot of edge cases for a relatively small convenience feature.
- We have received multiple AI-assisted HackerOne reports around bootstrap-specific behavior.
- Third-party implementations such as Cuprate did not implement this feature yet.
- Removing it reduces daemon complexity and attack surface.
- Simplifies FCMP++ integration, see for example https://github.com/seraphis-migration/monero/pull/355 and https://github.com/seraphis-migration/monero/pull/363.
