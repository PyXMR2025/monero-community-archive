# Original Description
Adds Nerva (XNV) as a monero_c target alongside monero/wownero/zano.

- `nerva_libwallet2_api_c` wrapper: adapted to the API Nerva actually exposes. `createTransaction`/`createTransactionMultDest` use Nerva's narrower signatures, seed/init/signMessage/exportKeyImages/exchangeMultisigKeys are implemented against Nerva's older signatures, and functions Nerva's wallet2_api doesn't have (coin control, address book, UR, Trezor, ...) are left out of the wrapper, header and export list -- every exported symbol is defined and backed by a real Nerva API.
- `nerva` submodule is pinned to the v0.3.0.0 release tag, same style as the monero submodule.
- `patches/nerva/`: `0001` CheckLinkerFlag source-dir and `0002` Version.cmake source-dir, both via `monero_SOURCE_DIR`. (The old `0003` apple-ios depends patch is gone, iOS support is upstream since nerva-project/nerva#99.)
- `impls/monero.dart`: `ffigen_nerva.yaml`, the `lib/nerva.dart` wrapper and its generated bindings, plus source checksums via `generate_checksum.sh`. `apply_patches.sh`, `build_single.sh`, `update_bindings.sh` and `generate_checksum.sh` all learn `nerva`.

On my fork the wrapper builds green for linux x86_64 and aarch64-apple-ios against the pinned submodule; `nerva.dart` is `dart analyze`-clean and the bindings/checksum sync checks pass.
