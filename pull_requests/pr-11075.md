# Original Description
https://github.com/monero-project/monero/issues/10132 

Release builds currently enable exception stack traces by default despite lacking useful debug symbols, producing noisy and unintelligible output. This change disables them by default for Release configurations while preserving explicit -DSTACK_TRACE=ON overrides; I’d appreciate any corrections if I have misunderstood the intended behavior or scope.
