# Original Description
When restoring from a hardware device in the CLI wallet (without specifying `--restore-height`), the user will currently be prompted with `Is this okay?`, before wallet creation is aborted upon the user responding with "no".

This seems a bit strange/unintuitive; this patch changes the behaviour so that the user will instead be prompted to specify a restore height after answering "no".
