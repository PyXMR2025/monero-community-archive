# Discussion History
## rroessler | 2026-08-18T00:06:16+00:00
The recommended fix is to allocate a _new_ `X509_NAME` then to assign it to both the subject and issuer of the certificate (since duplication does not use the original subject name):

```cpp
auto name = X509_NAME_new();
X509_NAME_add_entry_by_txt(name, "CN", MBSTRING_ASC, reinterpret_cast<const uint8_t *>(commonName), -1, -1, 0);

X509_set_subject_name(m_x509, name);
X509_set_issuer_name(m_x509, name);
X509_NAME_free(name);
```
