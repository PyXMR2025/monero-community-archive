# Original Description
Respect larger per-IP connection allowances under RPC load without shortening existing timeouts or changing non-HTTP timeout behavior.

Builds on the approach in #11296 by capping the scaled timeout penalty at the existing penalty. This allows longer timeouts for clients sharing an IP when the configured per-IP connection allowance is larger.
