# Original Description
removeTemporaryWallet() was only called on the successful save path (writeWallet). When the user starts creating or restoring a wallet and then navigates back to the wizard home, restart() cleared tmpWalletFilename and closed the wallet but never deleted the temporary wallet, .keys and .address.txt files, leaving wallet key files behind in the temp directory.

Capture the temporary filename before clearing it and remove the files after closing the wallet. On the successful save path the files were already removed, so the extra call is a harmless no-op.
