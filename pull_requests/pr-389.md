# Original Description
## Summary

Clarify the `pending` parameter in the Wallet RPC `get_transfers` documentation.

The previous wording ("Include pending transfers") could be interpreted as applying to all transfer categories.

This change makes it explicit that `pending` refers to pending, unconfirmed outgoing transfers, consistent with the Wallet RPC behavior discussed in #252.

## Changes

- Clarify the `pending` input description for `get_transfers`.
- Documentation-only change.
- No API or behavioral changes.

Closes #252
