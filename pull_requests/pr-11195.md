# Original Description
adds a fuzz target for Bulletproof+ deserialization and verification

the corpus covers valid proofs with 1, 2, 4, 8, and 16 outputs, with commitments encoded separately because they are omitted from serialized proofs and normally restored from `outPk`

tests:
- 866k libFuzzer runs with ASan from the initial seed, no crashes or timeouts
- 100k libFuzzer runs with ASan from the full corpus, final cov 1078 / ft 1622
- all 5 seed proofs round-trip and verify
