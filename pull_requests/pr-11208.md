# Original Description
Replaces the bloated and footgun-prone GNU Readline library with `linenoise`, a much simpler (and permissively licensed) alternative. This results in a huge decrease in LoC, as well as a binary size that is likely a bit smaller.

This patch also induces a few minor behavioural changes related to token completion, which are a bit hard to describe semantically, but nothing earth-shattering; try out the CLI wallet with these changes applied to see them for yourself.
