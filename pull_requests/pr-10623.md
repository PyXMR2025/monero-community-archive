# Original Description
Fixes:
1. Unaligned reading of `uint64_t` from a byte pointer (may crash on 32-bit ARM or RISC platforms)
2. Strict aliasing violation by reading `bucket_head2` from a byte pointer

Smaller version of #10622. Field member offsets of `bucket_head2` are still unaligned in-memory with this PR, but that behavior shouldn't result in undefined behavior or real unaligned memory accesses, just multiple slow aligned memory accesses.
