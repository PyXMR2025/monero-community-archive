# Original Description
It appears that in the `epee` TCP server code (see [here](https://github.com/monero-project/monero/blob/master/contrib/epee/include/net/abstract_tcp_server2.inl#L994)), `TCP_NODELAY` is explicitly disabled for every accepted connection. This forces the use of [Nagle's algorithm](https://en.wikipedia.org/wiki/Nagle%27s_algorithm) for both P2P and RPC; it would likely be worth enabling for the latter.
