# Original Description
## what

return every destination from `UnsignedTransaction::recipientAddress()` instead of only the first destination in each transaction

keep the returned addresses aligned with `amount()` and add a libwallet API regression test covering a two-recipient unsigned transaction

## why

wallets using `recipientAddress()` to review pay-to-many unsigned transactions currently receive an incomplete recipient list

fixes #10919

## testing

- full build with `BUILD_TESTS=ON` and `BUILD_GUI_DEPS=ON`
- `libwallet_api_tests`
- targeted red/green check for `WalletTest1.WalletUnsignedTransactionReturnsAllRecipients`
