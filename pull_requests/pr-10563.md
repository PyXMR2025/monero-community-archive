## iamamyth | 2026-05-09T20:15:26+00:00
Seems this would be clearer and more concise if you modeled both the ctor and assign operators with a private `swap/replace/consume` method which copies the source's values and then nulls/zeros the source. Then, ctor reduces to:
```
swap(m);
```

and assign to:
```
if (this != &m) {
    free(data);
    swap(m);
}
```
