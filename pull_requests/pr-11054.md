## thomasbuilds | 2026-08-10T06:36:35+00:00
This takes `json::run_handler`'s frame from 800 to 29,264 bytes (GCC 13.3, x86-64). It recurses, is capped at `EPEE_JSON_RECURSION_LIMIT_INTERNAL = 100`, and is fed from the RPC request body via `load_t_from_json`, so worst case goes ~80 KB → ~2.9 MB, on RPC threads that take the platform default stack (`http_server_impl_base.h:112` passes no attributes). Still under 8 MB, but a large margin reduction on an attacker-reachable path.

Is the stack-slot hardening worth that trade?
