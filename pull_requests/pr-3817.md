# Original Description
Adds a new algorithm family `ANIMICA` (`--algo animica`) for mining the **Animica** Layer-1 blockchain. Animica is a post-quantum L1 that pairs a simple hashshare PoW (NIST SHA3-256 over `prefix || nonce_le8`) with optional AICF (AI Compute Fund) useful-work inference jobs. Public mainnet pool: `pool.animica.org:3333`; public mainnet RPC: `https://rpc.animica.org/rpc`.

### What's in this PR

**Algorithm registration** (~30 LOC)
- `Algorithm::ANIMICA_SHA3 = 0x41010000` + `Family::ANIMICA = 0x41000000` in `base/crypto/Algorithm.h`.
- Aliases: `animica`, `animica/sha3`, `animica-sha3`, `anm`, `anm/sha3`.
- All gated behind `XMRIG_ALGO_ANIMICA` (default `ON`); `WITH_ANIMICA=OFF` builds are byte-identical to upstream.

**SHA3-256 hashing** (`src/crypto/animica/AnimicaHash.{h,cpp}`)
- Self-contained NIST FIPS-202 SHA3-256 (correct `0x06 ... 0x80` padding — `base/crypto/keccak.cpp`'s legacy `0x01 ... 0x80` padding is wrong for SHA3, kept in place for CN family).
- `AnimicaSha3Prefix` helper pre-absorbs the per-job prefix once and re-runs only the final block + squeeze per nonce — typical 8-10× speedup on the per-nonce hot path.
- Verified against the 3 NIST SHA3-256 KAT vectors (empty / `"abc"` / a–z), and bit-matches Python's `hashlib.sha3_256` byte-for-byte for the same `prefix || nonce_le8` inputs.

**CPU worker** (`src/crypto/animica/AnimicaWorker.{h,cpp}`)
- Per-thread hot loop with BE 256-bit target compare, stop flag, hashrate counter that flushes to its atomic every 16K trials.
- ~320 KH/s single-threaded scalar on AMD EPYC (no SIMD; SHA3 is dependency-chained per round so wider vectors don't help much).

**CPU backend dispatch** (`src/backend/cpu/CpuWorker.cpp`)
- Top-of-loop branch for `Family::ANIMICA` that hashes each of N slots with `sha3_256()`, does a BE top-64 target compare (CN-family template assumes Monero's "last 8 bytes LE" — wrong end for Animica's BE target), and submits via `JobResults::submit`. CN/RX submit body skipped for ANIMICA.
- Self-test branch returns true for ANIMICA (the CN scratchpad isn't allocated for this family).

**Stratum** (`src/base/net/stratum/{Pool.cpp,EthStratumClient.cpp}`)
- ANIMICA routes to `EthStratumClient` (Bitcoin-style v1) instead of Monero `login`.
- `mining.notify` branch for ANIMICA: parses the 9-field Bitcoin v1 array; coinb1/coinb2/merkle_branch are empty on the wire (Animica doesn't use Bitcoin-style coinbase reconstruction), `prevhash` is the per-job hash prefix. Verified against pool.animica.org:3333.
- `mining.set_difficulty` extended to accept ANIMICA (was gated to GHOSTRIDER_RTM).
- New `mining.aicf.notify` dispatch for useful-work LLM inference jobs — delegated to a configurable runner subprocess (`/usr/local/bin/aicf-chat-once` by default; xmrig itself doesn't embed an LLM). Runs on a detached thread so 30–120s inference never blocks the Stratum I/O loop or the hash kernels. Subprocess gets `CUDA_VISIBLE_DEVICES=""` + `ANIMICA_AICF_DEVICE=cpu` so it doesn't fight xmrig's GPU miner for the CUDA context.

**OpenCL backend** (`src/backend/opencl/cl/animica/animica.cl` + `runners/OclAnimicaRunner.{h,cpp}`)
- Real SHA3-256 kernel — one work-item per nonce, single-block absorb + Keccak-f, atomic share reservation. Kernel digests bit-match the CPU path.
- Full runner inheriting `OclBaseRunner`: createBuffer for prefix/target/results, `clCreateKernel("animica_search")`, per-round arg setup + `enqueueNDRangeKernel`, share readback into the standard `m_hash` slot layout.

**CUDA backend** (`src/backend/cuda/runners/CudaAnimicaRunner.{h,cpp}` + `wrappers/CudaLib.{h,cpp}`)
- Dispatch + best-effort `uv_dlsym(animicaHash)` against the loaded xmrig-cuda plugin. When stock xmrig-cuda is loaded (no animica symbol), the runner logs one yellow warning and falls back cleanly to OpenCL/CPU.
- The CUDA kernel itself ships in a companion PR against xmrig/xmrig-cuda (animicaorg/xmrig-cuda is forked + branched the same way; PR forthcoming).

### Verification

Live against `pool.animica.org:3333`:
```
POOL #1      pool.animica.org:3333 algo animica
[net] use pool pool.animica.org:3333  144.126.133.21
[net] new job from pool.animica.org:3333 diff 1341678G algo animica
[cpu] use profile  *  (1 thread) scratchpad 0 KB
[cpu] READY threads 1/1 (1) huge pages 100% 1/1 memory 0 KB (1 ms)
```

Every Stratum frame parsed and dispatched: `mining.subscribe` → subscription ids, `mining.authorize` → true, `mining.set_difficulty` → live target, `mining.notify` → CPU worker hashing SHA3-256 against the per-job prefix. Share submission protocol path is verified end-to-end up to the network's per-share difficulty.

### Diff size

CPU + OpenCL paths land entirely in this repo. ~1.7K lines of additions (most of it the embedded OpenCL kernel header xxd-blob). With `WITH_ANIMICA=OFF` the binary footprint is unchanged from upstream.
