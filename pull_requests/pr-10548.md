# Original Description
Related to #8819.

## What

This updates the wallet CLI transaction-proof wording so `check_tx_key`, `get_tx_proof`, and `check_tx_proof` state the important limitation called out in #8819: transaction proofs can show funds associated with a transaction/address, but they do not prove that those funds are currently spendable, unspent, unlocked, or not burned.

The same note is also printed after creating or checking a transaction proof successfully, so users see it in the command path rather than only in `help` output.

## Why

Issue #8819 notes that transaction proofs may be misunderstood as stronger spendability proof. This keeps the change narrow to the wallet CLI wording and does not change wallet behavior.
