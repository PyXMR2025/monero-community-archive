# Original Description
Adds two components to the tests directory:
1. `tests_common` a shared utility library for different types of tests
2. `gen_corpus` an executable to dynamically generate seed corpora for fuzzing during the build stage

Also updates the transaction fuzzing test to call `ver_non_input_consensus()` for different HF versions.

OSS-Fuzz downstream PR: https://github.com/google/oss-fuzz/pull/15893

Part of upstreaming Carrot/FCMP++

The registry stores these as `std::unique_ptr<seed_corpus_source>`, so at exit each object is deleted through a base pointer with a non-virtual destructor: the base destructor runs instead of the derived one, and the object is freed as the wrong type (8 vs 24 bytes). Clang flags it by default:

```
warning: delete called on 'fuzz::seed_corpus_source' that is abstract but has non-virtual destructor [-Wdelete-abstract-non-virtual-dtor]
```
