## jeffro256 | 2026-08-11T05:00:53+00:00
Max observed total ring members in any one transaction on the main chain is 4524 in f901cb282db0104f33d884fc01f751cd0846a3c20dc35c37ed47f6bb1d1f8af0. Testnet is 4509 in 75afa5c44762725faef28c5d49970581962b130bb75c904f1688d0d6f0958b88. Stagenet is 4000 in e75dc5567b1734d0f346915f7f44b6a7534046b711bb35d9581dc1fdd513053e.. Unfortunately, the max total ring member size for a new, valid CLSAG tx is more than both of those since 1 16-member CLSAG input is 625 bytes, including the key image and key offsets and 0 amount, and max TX size is 1MB. 1000000/625*16 ~= 25600 ring members. So the value here could be 25600, which is tighter than 31250.

On the other hand, max observed ring size in any one ring on the main chain is 4501 in 5e75b4596c234ad17d34c44c3f07da508afb985748b3066bbfe2923cedb0b81a. Testnet is 4391 in 4056527ad2e5bc95c18a0d7d5dc911757a24f6f807eeba172839e282632580d1. Stagenet is 2000 in e75dc5567b1734d0f346915f7f44b6a7534046b711bb35d9581dc1fdd513053e. Since for new, valid v16 txs, the ring size is <= 16, we can limit the ring size to 4501.

Source: I made a blockchain utility for this: https://github.com/jeffro256/monero/commit/292727f459cf1b0f136ed63731887d28fcc3050e
