# Original Description
Alternative to #10733. Uses 1 `memcpy()` call in `aesb_single_round()` and `aesb_pseudo_round()`, instead of 4 and 40, respectively. Removes `STATIC` and `INLINE` keywords which do nothing and are semantically incorrect. Diff is smaller.

# Discussion History

`static` in this context hides the function from visibility during the linking stage. So it wasn't pointless, although `inline` was particularly helpful here.
