# Original Description
The Windows and Macos/Ios build are currently not reproducible because they include timestamp of the time of build in their headers (ELF has no such field, so linux and android are not affected).

On mingw ld writes the datetime into the PE header's
On mac/ios the Mach-O debug map carries one mtime per object.

You can check the impacted released build of by:
`objdump -p libmonero_wallet2_api_c.dll | grep Time/Date`
`llvm-nm -a libmonero_wallet2_api_c.dylib | grep -m1 ' OSO '`

This PR replace the timestamp on the PE header's by the timestamp of the commit and disable this debug feature on mac/ios (you can not insert an alternative timestamp on it).

https://lld.llvm.org/MachO/ld64-vs-lld.html#zero-ar-date-enabled-by-default
https://sourceware.org/binutils/docs/ld/Environment.html
