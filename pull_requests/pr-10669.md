# Original Description
Refactors `crypto.h` and its dependencies such that the preprocessed size of the header is reduced dramatically. On my toolchain (GCC 16.1.1), the preprocessed size of `crypto.h` is 3.72MB in the `master` branch. In this branch, it is 207KB, a 17.9x reduction in size. This should help build times, especially with the FCMP++/CARROT integration, which adds dozens of translation units, almost all of which pull in `crypto.h`. 


Depends on #10666
