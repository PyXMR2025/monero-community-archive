# Original Description
Adds a C-compatible library `libmonero_license` to fetch licensing info with 2 functions:

- `size_t monero_license_num()`
- `monero_license_entry_t monero_license_get(size_t)`

A license entry contains the following information:
- Information to find source code (e.g. URLs)
- Copyright year
- Copyright holder
- License text

The information is maintained through an in-tree text file `sublicenses.txt.in`, which has the following format:

```
%%%%%%%%%%%%%%%%....%%%
<URL or source info>

Copyright (c) <year> <holder name>
<TEXT
.... 
.... MORE TEXT LINES
>

[REPEAT]
```

During the configure process, CMake writes the text file to the binary tree as a C source file containing a byte array. Then during the build process, it compiles that source file into the `libmonero_license` library.

Exiting BSD licenses we use, as well at most copyleft licenses, require supplying the user with instructions to obtain source code be included with binary distributions. This library will help us comply with that, and will hopefully help with the practical burden of #10964 . 

Currently, the license text array is 27KB.
