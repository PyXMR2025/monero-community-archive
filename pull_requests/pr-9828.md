I guess you could say it *must* be so because otherwise the birational map wouldn't work. Though that doesn't prove it directly.

Looking at the ed5519 curve, setting `y = 1`
```
ax^2 + y^2 = 1 + dx^2y^2
ax^2 + 1 = 1 + dx^2
ax^2 = dx^2
ax^2 - dx^2 = 0
x = 0
```
So `x` is always zero when `y = 1`.
