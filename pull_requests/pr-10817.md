# Original Description
We have two supported mingw builds: MSYS2 and depends. 

- MSYS2 does not produce statically linked binaries, even if we set `STATIC`.
- depends does produce statically linked binaries, and sets `STATIC` in its [toolchain file](https://github.com/monero-project/monero/blob/master/contrib/depends/toolchain.cmake.in#L6).

I don't see a reason why we would need to guarantee that MSYS2 builds _can_ build statically, so have it default to not link statically.
