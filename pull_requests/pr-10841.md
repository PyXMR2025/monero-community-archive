# Original Description
48080 and 58080 are within common ephemeral port ranges, which can make node_server tests intermittently fail to bind after recently closed TCP connections used the same local source port.

Use fixed unit-test ports outside those ranges and keep the tests on 127.0.0.1 instead of relying on 127.0.0.2 being configured.

Should fix the following flakey test

```
terminate called without an active exception
```

Relevant for #10650
