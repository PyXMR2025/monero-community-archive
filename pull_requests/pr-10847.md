# Original Description
This makes monerod look for the default `bitmonero.conf` under an explicit `--data-dir` before falling back to the existing default config path

So `./monerod --data-dir /tmp/node2` reads `/tmp/node2/bitmonero.conf` if present, instead of unconditionally picking up `~/.bitmonero/bitmonero.conf`

Explicit `--config-file` still wins, and the existing testnet/stagenet/regtest data-dir suffix handling is kept

Closes #10553

Tests:
- `cmake -S . -B build-config-data-dir -G Ninja -D CMAKE_BUILD_TYPE=Release -D BUILD_TESTS=ON`
- `cmake --build build-config-data-dir --target daemon unit_tests test_notifier -j2`
- `GTEST_FILTER="-DNSResolver.*:AddressFromURL.*:select_outputs.*" ./build-config-data-dir/tests/unit_tests/unit_tests` (1267 passed, 2 hardware-only skips)
- runtime temp HOME checks for default config, explicit `--config-file`, absolute and relative `--data-dir`, missing data-dir config fallback, and testnet/stagenet/regtest paths
