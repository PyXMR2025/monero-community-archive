# Original Description
## Summary
Adds a **Windows** counterpart to the existing Unix `gdb` / coredump debugging section in the README.

Covers practical operator steps that do not require a full debug build:

1. Event Viewer fault fields (module, exception code, offset)
2. WER `LocalDumps` registry setup for `monerod.exe`
3. `cdb` / WinDbg commands for dump and hung-process text stacks
4. Pointer to MSYS2 `make debug` for developers

Also notes that release binaries often lack symbols, and warns against publicly uploading dumps that may contain sensitive paths/credentials.

## Motivation
Fixes #3620 (open since 2018; Unix-only stack trace docs).
