# Original Description
Adds a check for iOS in addition to the existing `APPLE` check that is not sufficient for all creatures naturally occurring in apple's walled garden.

If CMAKE_SYSTEM_NAME is iOS and when passing different SDK that is ideally named `iPhoneSimulator.sdk` - as that is how apple names them in Xcode bundles - it will build the simulator, otherwise normal iOS build

We are technically missing out on the following SDK detections that are also available, but I don't currently have a way of testing if they build (and more importantly if the build works) so I'm leaving them out - but of course I can expand the if statement to include these as well if this is desired (I'd rather open a separate PR at some point in future though when I get to do something fun on these platforms, or at least their simulators.).

- AppleTVOS.sdk / apple-tvos
- AppleTVSimulator.sdk / apple-tvos-sim
- WatchOS.sdk / apple-watchos
- WatchSimulator.sdk / apple-watchos-sim
- XROS.sdk / apple-visionos
- XRSimulator.sdk / apple-visionos-sim


edit: also should I move -sim to `RUST_TOOLCHAIN`?
