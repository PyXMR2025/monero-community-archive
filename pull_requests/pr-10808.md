# Original Description
`transform_to_escape_sequence` builds the string body emitted by `dump_as_json`/`store_t_to_json`.

1. control bytes `0x00`-`0x07` and `0x0e`-`0x1f` are emitted verbatim, which RFC 8259 forbids inside a JSON string, so one such byte makes the response invalid JSON and an embedded `0x00` truncates C-string based parsers.
2. `0x0b` is emitted as `\v`, which is not a JSON escape; the parser reads it back as the letter `v`.

repro: serialise a value holding `0x01` or `0x0b`.
expected: both escaped as a six-character `\u00xx` sequence.
actual: `0x01` is copied out raw, `0x0b` becomes `\v`.
fix: escape every byte below `0x20`, the short escape where JSON defines one and `\u00xx` otherwise. reachable for any string value carrying attacker-influenced bytes (e.g. one decoded by `convert_from_url_format`). test added.
