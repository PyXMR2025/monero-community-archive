# Original Description
Based on #10673.

This removes the locations from translation files. It also updates the `*.ts` generation script to not include them in future runs.

Updating the translation files produces very spammy git diffs because line numbers change for almost every translation. Removing them makes future PRs easier to review. The locations are not needed to generate the `.qm` files.
