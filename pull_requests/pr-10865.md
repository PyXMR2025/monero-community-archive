# Original Description
## what

`export_key_images()` already derives a key image for each output with `generate_key_image_helper()`

This uses that generated key image for the exported pair and its signature, instead of reading `td.m_key_image` again after the cache consistency check

That keeps exports consistent when the cached key image is marked unknown or partial but the wallet can derive the full key image locally

## tests

- `cmake --build build/unit-key-image --target unit_tests -- -j2`
- `build/unit-key-image/tests/unit_tests/unit_tests --data-dir build/unit-key-image/tests/data --gtest_filter=wallet_storage.export_key_images_uses_generated_key_image`
- `build/unit-key-image/tests/unit_tests/unit_tests --data-dir build/unit-key-image/tests/data --gtest_filter=wallet_storage.*:wallet_keys_unlocker.*`
