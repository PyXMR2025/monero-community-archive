# Original Description
`get_tx_entries()` only checked the number of transactions returned by the daemon. A response containing a duplicate transaction could therefore omit another requested transaction and still pass that check

Compare each hash produced by `get_pruned_tx()` with the hash requested at the same position before adding it to the scan queue

Tests:
- `cmake --build build -j2`
- `ctest --test-dir build -R '^unit_tests$' --output-on-failure`
