# Original Description
Tor/I2P zones share the public zone's io_context. Shutdown previously stopped zone net servers before all zone connections had been closed, which could leave remaining Tor/I2P connection shutdown work unable to run and cause 5s per-connection waits.

Close all zone connections before stopping any zone net server, and make shutdown idempotent so duplicate stop requests do not re-enter the shutdown sequence.
